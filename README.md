# vanchezze.github.io

Source for **[vanchezze.github.io](https://vanchezze.github.io)**, the personal site of Ivan Rudiuk, a product engineer (full-stack, front-end depth, production AI) in Denver.

More about me: [GitHub profile](https://github.com/Vanchezze) · [LinkedIn](https://www.linkedin.com/in/ivan-rudiuk/)

## Run and deploy
- React (Create React App). All content lives in `src/data/data.json`.
- `npm install`, then `npm start` to run locally.
- Push to `main`, and GitHub Actions builds and deploys to GitHub Pages.
